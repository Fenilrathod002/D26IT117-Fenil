# MiniBank screenshot evidence pack

These PNGs are **rendered evidence images**, not screenshots taken from an IDE or terminal. Each code image is rendered from the current Java source with line numbers. Each output image is rendered from actual captured program output produced by the documented commands. This makes the evidence readable and reproducible where desktop capture was unavailable.

Run the commands in the project README to regenerate the application output. `EvidenceChecks` is a test-only verifier used for Practical 2–6 and 8 output evidence.
